# Shadow Empire | Теневая экономика

🌐 **Демо**: [Посмотреть на GitHub Pages](https://ВАШ_НИК.github.io/shadow-empire)

## Описание
Браузерная игра в стиле теневой экономики с системой:
- 🏦 Банковские операции
- 🏠 Недвижимость  
- 🌐 Даркнет-маркет
- ⚜️ Аукцион
- 👤 Система профилей

## Особенности
- Полностью на HTML/CSS/JavaScript
- Локальное хранение данных
- Адаптивный дизайн
- Система ролей (покупатель/продавец/админ)

## Тестовые аккаунты
- **Владелец**: owner/owner123
- **Тех. админ**: tech_admin/admin123  
- **Покупатель**: buyer1/123
- **Продавец**: seller1/123

## Технологии
- HTML5, CSS3, JavaScript
- Local Storage для хранения данных
- Адаптивный дизайн
