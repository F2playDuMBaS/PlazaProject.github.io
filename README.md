# Shadow Empire | Теневая экономика

Веб-приложение для симуляции теневой экономики с банком, недвижимостью, даркнетом и аукционом.

## Функциональность

- 💰 Банковская система с переводами
- 🏠 Недвижимость (дома, машины, бизнесы)
- 🌐 Даркнет маркет
- ⚜️ Аукцион
- 👥 Система ролей (покупатель, продавец, админ, владелец)
- 🛒 Корзина покупок

## Тестовые пользователи

- **Владелец:** login: `owner` / password: `owner123`
- **Тех. админ:** login: `tech_admin` / password: `admin123`
- **Продавец:** login: `seller1` / password: `123`
- **Покупатель:** login: `buyer1` / password: `123`

## Технологии

- HTML5, CSS3, JavaScript
- LocalStorage для хранения данных
- Адаптивный дизайн
